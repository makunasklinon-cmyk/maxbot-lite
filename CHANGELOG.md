# Changelog

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/). Версия
здесь соответствует константе `VERSION` в `maxbot_lite.py` (её же бот
показывает в `/status` и при старте).

## [lite 1.1] — 2026-09-25

### Добавлено
- Механизм аддонов: загрузчик `addons/` + контракт `register(ctx)` —
  необязательные фичи как отдельные файлы, без правки ядра.
- Демо-аддон `addons/addon_digest.py` — сводка непрочитанного раз в N минут,
  задуман как учебный пример для тех, кто пишет свой аддон.
- `↩️ ответить тапом` — инлайн-кнопки «↩️ #N» под снимком чата.
- `/find <слово>` — поиск по видимой истории чата (без БД).
- Мьют чатов через `.env` (`MUTED_CHATS`).
- `/open <имя>`, `/who` — открыть чат по названию / посмотреть, какой открыт.
- Подпись к пересылаемому файлу (уходит отдельным сообщением следом).
- `LICENSE` (MIT), этот `CHANGELOG.md`.
- `КАК-ДУМАТЬ-разведуя-MAX.md`, `ТЕХ-ПРИКОЛЫ-И-МИНЫ.md` — методички про
  привычки мышления при разведке и конкретные грабли платформ.
- README переработан: бейджи, Mermaid-диаграмма архитектуры, сворачиваемые
  блоки для Troubleshooting и «НЕ умеет».

## [lite 1.0] — первый публичный релиз

Ядро, вынесенное из приватного проекта maxbot 2.0: приём сообщений из всех
чатов MAX уведомлением в личку, отправка текста и файлов, `/reply`,
`/delete`, `/screen`, `/status`, `/logs`. Без истории/БД, без реального
скачивания медиа (заглушки), один пользователь (`OWNER_TG_ID`).
